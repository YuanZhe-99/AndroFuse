# Version History

## v0.2.1 (2026-11-27)

- **Zero-Setup Managed ADB (`internal/adb`, Release Packaging)**: Windows release builds now bundle official Android Platform Tools in `resources/windows/platform-tools/` (with `NOTICE.txt`, kept separate from `bin/`), and `adb.FindClient` / `adb.InstallPlatformTools` automatically download and Zip-Slip-safely extract `platform-tools` over Google HTTPS whenever ADB is absent on end-user PCs; Home stays quiet once ready and shows clear progress/retry banners only when missing.
- **Cross-Network First Pairing & Lossless ADB Merge (`PairMeshPhone`)**: Added `PairMeshPhone` and `rememberMeshPhone` / `mergeMeshRememberedLocked` so phones discovered on joined EasyTier networks pair directly without desktop ADB, display an `IMPORTANCE_HIGH` heads-up pairing notification (`Power.showPairNotification`), return full identity/`DeviceStatus` in `PairResponse`, and seamlessly merge temporary `mesh:<devID>` records into the real `HardwareHash` (`ro.serialno`) when ADB connects later.
- **Phone ADB Availability Telemetry & One-Time Enhanced Bootstrap**: `PermDefaultsV2` enables `Telemetry`, `ADBBeacon`, and `ScreenShare` by default on fresh installs; `Power.kt` reports `USBDebugOn`, `WirelessDebugOn`, and NSD-discovered `_adb-tls-pairing._tcp` ports (`WirelessADBPairPort`) while `tunnel.open` bridges both connect and pairing ports; desktop pulls up ADB silently or via the live-polling `Activate Enhanced mode` modal (`EnsureEnhancedAndRun` / `ActivatePairAndBootstrap`) to launch `dex.StartDaemon` once.
- **Consumer UX & End-User Copy Redesign**: Simplified Home (`My phones` hero, USB authorization banner, automatic `Found nearby or in your networks` discovery without raw virtual IPs), added sidebar `+ Add a phone` and guided 3-tab wizard (USB / Same Wi-Fi / Cross-network + collapsible Advanced fallback in `internal/gui/wizard.go`), added a pairing Cancel button, moved PC diagnostics out of Home into Settings › About and updates, and updated all `en` and `zh-Hans` UI strings (604 messages) to plain end-user copy.
- **Known Scope Boundaries & Checked Upstreams**: Physical Android APK build/pairing (`Power.kt`) and CI release script (`scripts/build.sh` / `.github/workflows/release.yml`) await live tag/device validation after push. Checked upstreams: Go `1.27.4` / MyGo `v0.10.0` / Rust `1.99.1` / scrcpy `v5.0.1` / EasyTier `v2.7.1` / Kyokai `v0.8.1` (`2026-11-27`).

## v0.2.0 (2026-11-27)

- **Persistent UID 2000 Enhanced Mode Daemon (`INV-01`, `INV-03`)**: Added `server/dexhelper` `Daemon.java`, `Daemon.kt`, and `AndroFuseDaemonProvider` with kernel-UID-checked scoped `IBinder` handoff (`getContentProviderExternal`), `ADD_TRUSTED_DISPLAY` probe, zero-copy `Os.socketpair` `ParcelFileDescriptor` IPC (`TX_ECHO_FD`), and `linkToDeath` auto-reattach. Unlocks full interactive phone mirroring, Samsung Native DeX (`dex:1920x1080/160` / `FlexDisplay`), and chromeless Independent App Windows (`start_app` + `apps.list` / `TX_LIST_APPS` + per-device `icon-cache/<hwHash>/apps.json`) over Companion TLS 1.3 without Wireless debugging.
- **Desktop Connection Strategies & Seamless Failover**: Added `ConnectionMode` (`both_adb`, `both_companion`, `companion_only`) and `AutoSwitch` under `Settings › Phones and picture`, providing instant Companion failover on 5G drops, automatic upgrade back to healthy Wi-Fi/USB ADB in `both_adb`, and in-session status strip + manual Reconnect controls.
- **Complete Phone Telemetry & Self-Healing Bootstrap**: `status.get` now reports `wifi_ipv4`, `wireless_adb_port`, `app_version`, `app_build_hash`, `companion_port`, `standby_running`, `accessibility_on`, and `daemon_*`; `Power.kt` restarts `_adb-tls-connect._tcp` NSD discovery on Wi-Fi transitions; and the desktop discovers changed ADB ports (with rate-limited `adb.FindWirelessPort` fallback) and proactively pulls up ADB at least once on Wi-Fi when APK hashes mismatch or Enhanced mode is down.
- **Low-Latency Direct LAN Routing & 5G Relay Bufferbloat Control**: `companionRoutes` now prioritizes direct Wi-Fi/LAN TCP (`WifiIPv4` / `Endpoint`) ahead of EasyTier mesh forwards (`isMeshRoute`), `companionStreamProfile` adapts bitrate/resolution/codec per path (`1.0–1.5 Mbps` / `960`px or `1280×720` with H.265 when HW decoder is available over 5G relays), and `tuneVideoConn` / `Daemon.java` / `Daemon.kt` cap video socket (`64 KB`) and pipe (`32 KB`) buffers.
- **Known Scope Boundaries & Checked Upstreams**: Brief frame-rate dips during full-screen animations over bandwidth-constrained 5G relays remain; dynamic congestion-controlled bitrate adaptation is deferred to a future release. Checked upstreams: Go `1.27.4` / MyGo `v0.10.0` / Rust `1.99.1` / scrcpy `v5.0.1` / EasyTier `v2.7.1` / Kyokai `v0.8.1` (`2026-11-27`).

## v0.1.0 (2026-11-26)

- **Native Desktop & Core (`windows/arm64` & `windows/amd64`)**: Unified Go (`1.27`), MyGo (`v0.10.0`), and Rust 2024 (`core/androfuse-core`, C ABI v6) application under `GPL-3.0-only`, with Ed25519 helper bundle signing (`tools/sign`), MyGo signed updater configuration, and native PE verification (`tools/checkpe`).
- **Media Foundation DXVA & Audio**: Zero-allocation DXVA/D3D11 H.264/HEVC NV12 video pipeline into `ui.Bitmap.UpdateYUV`, shared-mode WASAPI PCM playback and mic capture (`androfuse_mic_*`), PNG screenshots, and zero-reencode fragmented MP4 recording.
- **Samsung Native DeX, Mirroring, App Windows & Camera**: `SemWifiDisplayConfig` loopback Native DeX (`server/dexhelper`, interactive UHID mouse/keyboard/scroll, resize, detached `serve` with grace-period `Reattach`), concurrent Android screen mirroring, chromeless independent app windows with real icons (resuming across One UI live-icon aborts), and phone camera streaming with in-place front/rear lens switching.
- **Kyokai-Style V3 Desktop UI**: Docked main-window panes, split view, pop-out/dock without reconnecting, address-only connect with port discovery, `+` picker, `Ctrl K` search, remembered phones (`devices.json`), multi-network EasyTier settings (up to 8 networks), tray per-phone submenus, and plain-language error messages backed by scrubbed logs (`Save logs…`).
- **Embedded EasyTier v2.7.1 Mesh & Companion (`arm64-v8a`)**: User-space `--no-tun` mesh embedded in both desktop and Android cores with compact `AF-<p|c>-<id>` peer filtering and low-power mobile mode; optional ECDSA P-256 TLS 1.3 Android Companion APK (`AndroFuse-0.1.0-android-arm64.apk`) with Keystore-sealed identity, per-computer pairing, background standby service, Wireless debugging discovery/tunneling, and mobile-data screen sharing (`MediaProjection`).
- **Built-In Headless Android VM & Opt-In Local MCP**: On-demand downloadable native Android 16 AVD runner (`internal/vm`) and default-disabled `127.0.0.1` local MCP server with per-tool approval cards.
- **Known Scope Boundaries**: Miracast sink remains hidden/disabled due to undocumented Windows APIs triggering `qcwlan8280.sys` kernel BSODs; real-hardware Windows 11 `x64` / Windows 10 verification, physical USB unplug re-test, and post-reboot 5G ADB alternatives are tracked for subsequent releases.
- **Checked Upstreams**: Go `1.27.4` / MyGo `v0.10.0` / Rust `1.99.1` / scrcpy `v5.0.1` / EasyTier `v2.7.1` / Kyokai `v0.8.1` (checked `2026-11-26`).

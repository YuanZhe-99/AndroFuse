# Vendor logo sources

Monochrome maker marks that AndroFuse draws in a phone's avatar when what the phone says about
itself (its maker, brand, model or name) names a known maker (`internal/gui/vendorlogo.go`). They
are the phone makers' files from the set the same author keeps for EasyTier MyGo and Kyokai.

All **8** files are [Simple Icons](https://simpleicons.org/) SVGs (CC0 1.0), byte-identical in path
data with the `simple-icons` package.

**Trademarks.** Every file here is a trademark of the brand named in its row. The marks are used
only to identify the maker of a device, as nominative use; their use implies no affiliation with
or endorsement by the owner, and a mark will be removed if its owner asks. Copyright status (the
"License" column) is separate from trademark rights, which CC0 does not waive. These files are not
part of AndroFuse's GPL-3.0 source.
